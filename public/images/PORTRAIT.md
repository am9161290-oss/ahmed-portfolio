# Portfolio Portrait

The portrait attached in the conversation was not made available as a file in the project.

To publish the real photo for every visitor, save the original photo as
`public/images/ahmed-portrait.jpg`. The About section already uses this path.

The About section also supports uploading a JPG, PNG, or WebP photo directly.
That preview is resized and stored locally in the current browser only. It does
not upload the photo to a server or update the deployed site for other visitors.
